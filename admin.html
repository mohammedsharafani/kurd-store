📊 Google Analytics
Track visitors and page views
How to set up:
1. Go to analytics.google.com
2. Create account → New Property → Web
3. Enter your GitHub Pages URL
4. Get your Measurement ID (looks like G-XXXXXXXXXX)
5. Paste it below and save ✅
📧 Order Confirmation Emails
Auto-send email to customers after ordering
How to set up (free):
1. Go to emailjs.com → Sign up free
2. Add Email Service → Connect Gmail
3. Create Email Template — use these variables:
  {{to_email}} {{customer_name}} {{order_items}} {{order_total}} {{payment_method}}
4. Get your Service ID, Template ID, Public Key
5. Paste them below ✅
